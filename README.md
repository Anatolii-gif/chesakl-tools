# CHESAKL TOOLS

Статический сайт для GitHub Pages: NFC владельцев + QR-коды инструментов.

## Возможности
- Привязка NFC-метки к имени владельца внутри сайта.
- Привязка QR-кода к инструменту через встроенную камеру.
- Переключение между владельцами по NFC.
- Отдельные активные журналы для всех владельцев.
- QR-сканирование без выхода из сайта.
- Статус «Выдано» и ручная кнопка «Возврат».
- История операций.

## Публикация
1. Создайте репозиторий `chesakl-tools`.
2. Загрузите все файлы из ZIP в корень.
3. Settings → Pages → Deploy from a branch → main → /(root).

## Важно
- NFC работает в Chrome на Android через HTTPS.
- Камера требует HTTPS и разрешение.
- Данные хранятся в браузере конкретного телефона. Для нескольких телефонов нужна облачная база.
